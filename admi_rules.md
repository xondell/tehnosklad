# Как пользоваться админ-панелью Tehnosklad

## Вход

Откройте:

https://tehnosklad123.vercel.app/admin/login

Логин — email, который вы создали в Supabase → **Authentication → Users**.
Пароль — тот, который вы придумали при создании этого пользователя. Готового
пароля в проекте нет.

Если после входа появляется отказ в доступе, пользователю ещё не назначена
роль `admin`. Роль назначается один раз в Supabase SQL Editor инструкцией из
`docs/supabase-setup.md`, раздел «Первый Auth user/admin».

## Что находится в панели

- **Dashboard** — общая статистика.
- **Категории** — разделы каталога. Для каждой категории заполните русский и
  румынский вариант.
- **Характеристики** — группы, параметры и варианты выбора для фильтров.
- **Товары** — карточки товаров, цены, наличие, переводы и публикация.
- **Заявки** — обращения покупателей и их статусы.
- **Настройки** — телефон, адрес и график работы магазина.
- **Изображения / orphan media** — проверка загруженных файлов.

## Как добавить категорию

1. Откройте **Категории** → **Создать**.
2. Выберите тип изображения и порядок сортировки.
3. Заполните название, slug и описание на русском.
4. Переключите язык на румынский и заполните второй перевод.
5. Сначала сохраните категорию как черновик.
6. Публикуйте категорию только после проверки обоих переводов.

Slug пишется латиницей: `holodilniki`, `aragazuri`, без пробелов и символов
кириллицы.

## Как добавить товар

1. Сначала создайте или выберите опубликованную категорию.
2. Откройте **Товары** → **Создать**.
3. Заполните бренд, модель, уникальный SKU, цену в MDL и наличие.
4. Добавьте русский и румынский переводы: имя, slug, короткое и полное
   описание.
5. Сохраните как черновик и проверьте карточку.
6. Загрузите JPEG, PNG, WebP или AVIF до 5 MiB. Для каждого изображения
   заполните alt-текст на обоих языках.
7. Опубликуйте товар только после проверки цены, наличия, переводов и фото.

Публичный товар должен иметь корректную опубликованную категорию и оба
перевода. Не используйте одинаковый slug или SKU для разных товаров.

## Тестовый товар

Сейчас в production есть один опубликованный тестовый товар:

- SKU: `TEST-STAGE8-001`;
- slug: `test-stage8-001`;
- категория: **Тестовые товары / Produse de test**;
- цена: 999 MDL;
- наличие: 1 штука.

После проверки удалите или архивируйте его через **Товары**, а затем удалите
тестовую категорию, если она больше не нужна. Сначала уберите публикацию
товара, затем публикацию категории. Не удаляйте реальные заявки.

## Заявки покупателей

Откройте **Заявки**, чтобы увидеть имя, телефон, комментарий и источник.
После обработки изменяйте только статус. Если Telegram временно недоступен,
заявка всё равно остаётся в базе — повторную отправку выполняйте из карточки
заявки.

## Настройки магазина

В **Настройки** изменяйте телефон, адрес и график сразу на русском и
румынском. После сохранения откройте публичные `/ru` и `/ro` и проверьте
телефонную ссылку и часы работы.

## Безопасность

- Никому не отправляйте пароль администратора.
- Не вставляйте service-role key в браузер, GitHub, README или `NEXT_PUBLIC_*`.
- Не создавайте администратора через `user_metadata`.
- Перед публикацией дважды проверьте цену и наличие.
- Нажимайте «Сохранить» один раз и дождитесь сообщения об успехе.
- После работы нажимайте **Выйти**.
